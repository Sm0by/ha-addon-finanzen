# Finanzen

Depot, Fixkosten und Monatsliste als App in Home Assistant. Ersetzt ein Google Sheet mit Apps Script.

- Oberfläche in der Seitenleiste, Anmeldung über Home Assistant
- Kurse von Yahoo Finance oder per XPath von Webseiten
- Tagesverlauf, Zahlungsliste am Monatsanfang, Erinnerungen mit Knopf „Bezahlt“
- Sensoren per MQTT, Import aus dem Google Sheet, Export als .xlsx

Siehe den Reiter **Dokumentation**.
